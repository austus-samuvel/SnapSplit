# SnapSplit

## One snap. Everyone's share.

SnapSplit is an AI-powered receipt and expense splitting application. It uses Gemini Vision to extract items, prices, tax, total amount, and automatically categorize the expense from a receipt image.

Users can enter the people sharing the bill, assign items to each person, and SnapSplit calculates each person's share including tax. The final bill can also be shared through Gmail.

## Features

- Upload receipt images
- AI-powered receipt analysis using Gemini
- Automatic expense category detection
- Extract items, quantity, rate and amount
- Split items between multiple people
- Automatic tax distribution
- Verify the final split against the receipt total
- Share the bill through Gmail

## Technologies Used

- Python
- Streamlit
- Google Gemini API
- Gemini Vision
- Gmail
- JSON
